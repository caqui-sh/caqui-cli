# Audit Dimension Specification *(Atomic & Terminal)*: Macro Structure - Structure (macro_structure.dimension.md)

This specification defines the rules for the **Macro Structure** dimension. It audits the global organization and skeletal compliance of the target asset, answering: *Is the global, hierarchical layout and skeletal architecture of containers (Folder -> File -> Section -> Block) correctly structured according to template specifications (minimizing template deviations / maximizing skeletal compliance)?*

This dimension exists under the [**Structural Architecture (Blueprint)**](audit-pillar/structure.pillar.md) pillar.

This dimension is [**Objective & Discrete (Zero-Tolerance)**](audit-nature/objective_discrete.nature.md) in nature.

---

## Dimension Constraints

* **Macro Structure (Hierarchical Skeletal Layout)**:
  - **Constraint**: The nested structural architecture of folders, filenames, outline hierarchies, and container schemas must conform to designated templates.
  - **Asymmetric & Layered Nature**: Macro Structure is hierarchical and exists across multiple nested container layers. Each parent layer sets the layout container boundaries for its child layers.
  - **Audit Focus**: Catches structural layout omissions, missing mandatory files or headings, incorrect file nesting, and out-of-order container skeletons.
  - **Mutual Exclusive Distinction**: Evaluates only the global container blueprint. It does not audit local, terminal line-level formatting (Notation Conformance) or content depth calibration (Perspective Depth).
